🏠仓库管理

git init 初始化一个新的 Git 仓库 ▶
git init在当前目录初始化
git init <dir>在指定目录初始化
git init --bare <dir>初始化裸仓库（用于远程共享）
git clone 克隆远程仓库到本地 ▶
git clone <url>克隆远程仓库
git clone <url> <dir>克隆到指定目录
git clone -b <branch> <url>克隆指定分支
git clone --depth 1 <url>浅克隆（只拉取最新一次提交）
git clone --recursive <url>同时克隆子模块
git remote 管理远程仓库连接 ▶
git remote -v查看所有远程仓库及 URL
git remote add <name> <url>添加远程仓库
git remote remove <name>移除远程仓库
git remote rename <old> <new>重命名远程仓库
git remote set-url <name> <url>修改远程仓库 URL
git remote show <name>查看远程仓库详细信息
git remote prune <name>清理已删除的远程分支引用

📝基本工作流

git status 查看工作区和暂存区状态 ▶
git status查看状态
git status -s简短格式输出
git status -sb简短格式 + 当前分支信息
git status --ignored同时显示被忽略的文件
git add 将文件添加到暂存区 ▶
git add <file>暂存指定文件
git add <dir>暂存整个目录
git add .暂存当前目录所有更改
git add -A暂存所有更改（包括删除）
git add -p交互式选择暂存（逐块确认）
git add -u只暂存已跟踪文件的修改和删除
git commit 提交暂存区的更改 ▶
git commit -m "msg"提交并附带消息
git commit -a -m "msg"跳过暂存，直接提交已跟踪文件的修改
git commit --amend修改最近一次提交（追加到上一次）
git commit --amend -m "new"修改最近一次提交的消息
git commit --amend --no-edit追加更改但不修改消息
git commit -m "title" -m "body"标题 + 正文
git commit --allow-empty允许空提交
git log 查看提交历史 ▶
git log查看提交历史
git log --oneline每行显示一条简洁提交
git log --oneline --graph --all图形化显示所有分支历史 ⭐
git log -p显示每次提交的差异
git log --stat显示每次提交的文件变更统计
git log -<n>只显示最近 n 次提交
git log --author="name"按作者过滤
git log --since="2024-01-01"按日期过滤
git log --grep="keyword"按提交消息关键词过滤
git log -S "code"搜索添加/删除了特定代码的提交
git log branch1..branch2branch2 有但 branch1 没有的提交

🌿分支管理

git branch 管理分支 ▶
git branch列出本地分支
git branch -a列出所有分支（含远程）
git branch -r只列出远程分支
git branch -vv查看本地分支与远程的关联
git branch <name>创建分支
git branch <name> <commit>从指定提交创建分支
git branch -d <name>删除已合并的分支
git branch -D <name>强制删除分支
git branch -m <old> <new>重命名分支
git branch --merged查看已合并到当前分支的分支
git branch --no-merged查看未合并到当前分支的分支
git switch 切换分支（Git 2.23+）新 ▶
git switch <branch>切换到已有分支
git switch -c <name>创建并切换到新分支
git switch -c <name> <commit>从指定提交创建并切换
git switch -切换到上一个分支
git checkout 切换分支 / 恢复文件 ▶
git checkout <branch>切换分支
git checkout -b <name>创建并切换到新分支
git checkout -切换到上一个分支
git checkout <commit>切换到指定提交（分离 HEAD）
git checkout -- <file>丢弃工作区更改（恢复文件）
git checkout <commit> -- <file>恢复文件到指定提交的状态
git merge 合并分支 ▶
git merge <branch>将指定分支合并到当前分支
git merge --no-ff <branch>强制生成合并提交（禁用快进）
git merge --ff-only <branch>只在能快进时才合并
git merge --squash <branch>压缩合并（所有更改合并为一个提交）
git merge --abort取消正在进行的合并
git merge --continue解决冲突后继续合并
git rebase 变基 —— 将提交应用到另一个分支的顶端 ▶
git rebase <branch>将当前分支变基到指定分支
git rebase -i <commit>交互式变基 ⭐（合并/编辑/删除提交）
git rebase --continue解决冲突后继续变基
git rebase --abort取消变基
git rebase --skip跳过当前提交
git rebase --onto <new> <old>将分支 old 之后的提交移到 new
交互模式命令： pick(保留) reword(改消息) edit(修改内容) squash(合并) fixup(合并+丢弃消息) drop(删除)

☁️远程协作

git push 推送本地提交到远程仓库 ▶
git push推送到默认远程的当前分支
git push <remote> <branch>推送到指定远程的指定分支
git push -u <remote> <branch>推送并设置上游跟踪
git push --all <remote>推送所有本地分支
git push --tags推送所有标签
git push -d <remote> <branch>删除远程分支
git push --force强制推送 危险
git push --force-with-lease更安全的强制推送（推荐）
git fetch 从远程获取更新但不合并 ▶
git fetch从默认远程获取所有更新
git fetch <remote>从指定远程获取
git fetch <remote> <branch>获取指定分支
git fetch --all从所有远程获取
git fetch --prune同时清理已删除的远程分支引用
git pull 从远程拉取并合并（= fetch + merge） ▶
git pull拉取并合并
git pull <remote> <branch>拉取指定远程的指定分支
git pull --rebase拉取并变基（= fetch + rebase，推荐 ⭐）
git pull --rebase --autostash变基前自动 stash 本地更改
git pull --ff-only只在能快进时才合并

↩️撤销与回退

git reset 重置 HEAD 到指定状态 ▶
git reset --soft <commit>只移动 HEAD，更改保留在暂存区
git reset --soft HEAD~1撤销最近一次 commit，更改保留在暂存区
git reset <commit>移动 HEAD，重置暂存区，保留工作区（默认）
git reset HEAD <file>取消暂存指定文件
git reset --hard <commit>完全回退，丢弃所有更改 危险
git reset --hard origin/main重置到远程 main 分支的状态
git revert 创建新提交来撤销某次提交（安全，不修改历史） ▶
git revert <commit>撤销指定提交
git revert <c1>..<c2>撤销一个范围内的提交
git revert -n <commit>撤销但不自动提交
git revert --continue解决冲突后继续
git revert --abort取消撤销
git restore 恢复文件（Git 2.23+）新 ▶
git restore <file>丢弃工作区更改
git restore --staged <file>取消暂存
git restore --source <commit> <file>从指定提交恢复文件
git restore -SW <file>同时取消暂存并丢弃工作区更改
git stash 暂存当前工作区的修改 ▶
git stash暂存当前修改
git stash push -m "msg"暂存并添加描述
git stash push -u暂存时包含未跟踪文件
git stash list列出所有暂存
git stash pop恢复最近的暂存并删除记录
git stash apply恢复最近的暂存但不删除记录
git stash drop stash@{n}删除指定暂存
git stash clear清空所有暂存
git stash branch <name>从暂存创建新分支
git stash show -p查看最近暂存的完整差异

🔍查看历史与追溯

git show 查看提交详情 ▶
git show查看最新提交的详情
git show <commit>查看指定提交
git show <commit>:<file>查看某提交中某个文件的内容
git show --stat <commit>查看提交的文件变更统计
git diff 查看文件差异 ▶
git diff工作区 vs 暂存区
git diff --staged暂存区 vs HEAD
git diff HEAD工作区+暂存区 vs HEAD
git diff <commit1> <commit2>两个提交之间的差异
git diff <branch1> <branch2>两个分支之间的差异
git diff --name-only只显示变更的文件名
git diff --stat显示变更统计
git blame 查看文件每行的修改信息 ▶
git blame <file>查看每行的作者和提交
git blame -L 10,20 <file>查看指定行范围
git blame -w <file>忽略空白变更
git blame -M <file>检测行移动
git reflog 查看 HEAD 移动记录（找回"丢失"的提交） ▶
git reflog查看所有 HEAD 移动记录
git reflog <branch>查看指定分支的移动记录
git reflog --date=iso显示完整日期

git tag 创建和管理标签（常用于发布版本） ▶
git tag列出所有标签
git tag -l "v1.*"按模式列出标签
git tag <name>创建轻量标签
git tag -a <name> -m "msg"创建附注标签

⚙️配置管理

git config 配置 Git 行为 ▶
git config --global user.name "Name"设置用户名
git config --global user.email "e@m"设置邮箱
git config --global alias.co checkout创建别名
git config --global pull.rebase truepull 默认变基
git config --list列出所有配置

git rebase -i <commit>编辑指定提交之后的所有提交

git cherry-pick <commit>挑选单个提交

💡常用工作流速查

修复最近一次提交 追加忘记的文件或修改提交消息 ▶
git add <file>暂存忘记的文件
git commit --amend --no-edit追加到上一次提交
git commit --amend -m "new"修改提交消息
撤销未推送的提交 三种撤销力度 ▶
git reset --soft HEAD~1撤销 commit，更改保留在暂存区
git reset HEAD~1撤销 commit+add，更改保留在工作区
git reset --hard HEAD~1彻底丢弃 危险
合并多个提交（Squash） 将多个 commit 合并为一个 ▶
git rebase -i HEAD~3编辑最近 3 个提交
编辑器中将要合并的提交标记为 squash 或 fixup
变基到最新 main 同步主分支的最新代码 ▶
git fetch origin获取远程更新
git rebase origin/main变基到最新 main
或一行搞定：git pull --rebase origin main
回退已推送的提交 安全方式：用 revert 而不是 reset ▶
git revert <commit>创建新提交来撤销
git push推送撤销提交
暂存工作处理紧急任务 用 stash 临时保存进度 ▶
git stash暂存当前更改
... 处理紧急任务 ...
git stash pop恢复之前的工作
找回丢失的提交 用 reflog 找回误删的提交 ▶
git reflog找到丢失提交的 hash
git checkout <hash>切换到该提交
git switch -c rescue-branch从该提交创建分支恢复
